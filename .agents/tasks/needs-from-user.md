# 사용자 확인 요청 (비차단)

## 1. 공식 수종 목록: 확보 완료, 최신 여부만 확인 부탁

- 사용 자료: Q-net 공개문제 "공개문제[2020년 조경기능사 수목감별 표준수종 목록 변경]" (등록일 2020.01.14)
  - https://www.q-net.or.kr/cst006.do?id=cst00602&gSite=Q&brdId=Q006&artlSeq=5206512
  - 첨부 "2020년 조경기능사 수목감별 표준수종 목록[공개].hwp" (sha256 26f70f14…7ff1), 120종. 2026-10-19에 직접 받아서 추출함
  - 추출본: `.agents/tasks/official-species-list-2020.txt`
- 2020년 이후 새로 바뀐 목록을 Q-net에서 찾지 못했음. 2021년 이후 개정 공지(HWP/PDF)가 있으면 그 파일을 주세요.

## 2. 시험 진행 방식 공식 안내 (있으면 좋음)

공식 문서로 확인한 것: 120종 안에서만 출제되고, 답은 목록에 있는 이름 그대로 써야 정답 (예: 복자기 ○, 복자기나무 ×).

비공식 출처(수험 블로그)로만 확인한 것: 모니터에 사진 20문항, 10점 만점(문항당 0.5점), 답안지에 수기로 작성, 사진이 자동으로 넘어감. 문항당 표시 시간은 출처마다 10~30초로 다름.

- 필요한 파일: Q-net 조경기능사 "실기 공개문제"(수목감별 요구사항/수험자 유의사항이 들어 있는 HWP/PDF/ZIP, Q-net 자료실 > 공개문제) 또는 시험장 안내문
- 이 파일이 없어도 모의고사는 문항당 시간을 바꿀 수 있게 만들어 두므로 작업은 계속할 수 있음.
