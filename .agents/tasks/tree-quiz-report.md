## 1. 만든 것

조경기능사 실기 **수목감별**(공식 120 표준수종) 대비용 무료·비상업 PWA.
백엔드·로그인 없음, 학습 기록은 브라우저 IndexedDB에 저장, 오프라인 동작(PWA).

### 학습 모드 (의뢰서 4개 모두 구현 + 대시보드)
- **오늘의 학습**: FSRS(`ts-fsrs`)가 복습 카드 + 새 카드를 배정. 사진 → 수종 맞히기(객관식 인출 연습).
- **실전 모의고사**: 공개문제 형식(기본 20문항)으로 이름 직접 입력 채점. 문항당 시간(무제한/10·15·20·30초) 및 문항 수(10~40) 조절.
- **약점 집중**: 오답 많은 수종 + 자주 헷갈린 쌍을 한 세션에 섞어 교차 학습.
- **도감**: 과·상록/낙엽·부위·이름 필터, 수종 상세(형태·구분 포인트·사진별 출처).
- **대시보드**: 수종별 숙달도(FSRS 회상률), 학습 범위, 합격 가능성(이항분포 추정), 연속 학습일, 학습 기록 JSON 내보내기/가져오기.
- **출처 페이지**: 수종 목록 출처, 사진 제공처·라이선스 통계, 수종별 사진 크레딧 전체.

### 학습 설계(연구 근거) — 모두 구현
- 인출 연습(읽기 전 퀴즈), 간격 반복(FSRS 카드·복습/신규 배정), 교차 학습(셔플·혼동 수종 혼합),
  예시 다양성(문제마다 사진 랜덤·최근 사진 회피), 무작위 출제(Fisher-Yates·같은 수종 연속 금지),
  어려운 오답 보기(같은 속·혼동 그룹 우선), 형식 전환(객관식→타이핑, 띄어쓰기·별칭 인정, 오타 근접은 "거의 맞음"),
  즉시 교정 피드백(정답·학명·구분 포인트·고른 수종과 사진 비교).

### 접근성
키보드로 퀴즈 풀이(Enter 제출/다음), 사진 대체 텍스트, 명도 대비, 모바일 우선 반응형, 하단 탭 내비게이션, 다크 모드 대응.

### 기술 스택 / 구조
- Vite 8 + React 19 + TypeScript 5.9 + `vite-plugin-pwa` 2, 상태 저장 Dexie(IndexedDB).
- 순수 로직은 `src/lib/`(shuffle·matching·distractors·fsrs·question·data·storage)로 분리 → 단위 테스트 용이.
- 데이터는 `data/species.json`(앱 번들에 포함) + `public/photos/`(WebP).

## 2. 실행 방법 / 배포 방법

```bash

CONTACT_EMAIL="you@example.org" npm run data:fetch  # 사진 파이프라인 재실행(idempotent)
```

### 배포 (운영비 0원)
- **GitHub Pages**: `.github/workflows/deploy.yml`가 `main` 푸시 시 자동 빌드·배포. 저장소 Settings → Pages → Source를 "GitHub Actions"로. 하위 경로(`/<저장소명>/`)는 워크플로가 `BASE_PATH`로 처리.
- **Cloudflare Pages**: 빌드 `npm run build`, 출력 `dist`, 루트 배포 시 `BASE_PATH` 비움.
- 무료 한도 준수: 사진 WebP(긴 변 800px), 최대 파일 296KB(≪25MB), 총 1,908개(≪20,000개).

## 7. 끝내지 못한 / 추후 과제

- **사진 부위 태그**: 대부분 `whole`. iNaturalist annotation 연동 또는 수동 검수로 잎/수피/꽃/열매 분산 필요(현 상태로도 학습엔 문제 없음).
- **히어리 사진**: 공개 CC 이미지 희소로 1장. 추가 확보 시 보강(파이프라인 `ONLY=hieori`로 재실행하면 자동 반영).
- **설명 텍스트 전수 검수**: `needs-review` 2종은 전문가 확정 권장. 나머지도 시험 대비 핵심 위주로 작성했으나 교차 검수하면 품질 향상.
- **나쁜 사진 수동 제외 UI**: 스키마에 `excluded` 플래그는 있으나(검증·표시에 반영됨) 전용 로컬 검수 화면은 미구현. 현재는 JSON에서 플래그로 제외 가능.
